# Переустановка · InTreatment

Веб-приложение с аудиопрактикой и интерактивной тетрадью для исследования убеждений.

Автор программы и аудиозаписей — Екатерина Логинова.

## Файлы

- `index.html` — приложение; сборка и серверная часть не требуются.
- `audio/p01.mp3`–`audio/p17.mp3` — 17 аудиозаписей.
- `author-round.jpg` — фотография автора.
- `pdf/` — локальные шрифты и jsPDF для экспорта тетради.
- `.nojekyll` — публикация статических файлов без обработки Jekyll.

## Публикация в GitHub Pages

В **Settings → Pages → Build and deployment** выбрать:

1. **Source:** `Deploy from a branch`.
2. **Branch:** `main`.
3. **Folder:** `/(root)`.
4. Нажать **Save**.

Последующие изменения в `main` будут публиковаться автоматически.

## Аудио

Записи сохранены в MP3, моно, 44,1 кГц, 96 кбит/с. Применена щадящая фильтрация низкочастотного фона, спектральное шумоподавление с ограничением 4 дБ и ограничение пиков. Темп и высота голоса не менялись. Исходный архив хранится отдельно.

Ответы в тетради сохраняются в локальном хранилище браузера пользователя.
